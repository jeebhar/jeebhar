# Reel cover images

Reel covers are set per reel in the content editor (`/#/admin`) as **Cover photo**:

- **Upload…** a frame from the reel (best — it shows your own content), or
- paste any image URL. The defaults are free photos from [Unsplash](https://unsplash.com),
  loaded from `images.unsplash.com` as Unsplash's licence allows.

Instagram does not let other websites load reel covers, so a cover always has to be
set here. If a cover is empty or fails to load, the card shows a branded tile instead
of a broken image.

Covers display at 3:4 portrait. About 720 × 960 px is plenty.

Files placed in this folder are still served at `/reels/<file>` if you prefer to
commit covers to the repository.
